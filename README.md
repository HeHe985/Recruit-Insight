# Recruit Insight

## 프로젝트 개요

"데이터와 AI로 취업의 불확실성을 통찰(Insight)로"

Recruit Insight는 재무제표 기반 기업 분석과 AI 추천을 결합한 올인원 채용 관리 플랫폼
단순 채용 공고 나열을 넘어, 공공 데이터를 활용한 기업 재무 분석과 LLM 기반 개인 맞춤형 추천을 제공하여 구직자가 보다 합리적인 의사결정을 할 수 있도록 돕는 것을 목표로 함

---

## 핵심 가치

* Trust: 재무 건전성과 성장성을 수치 기반으로 검증
* Insight: AI가 사용자 정보와 공고 맥락을 분석하여 매칭 점수와 추천 사유 제공
* Efficiency: 채용 공고 관리, 북마크, 이력서 및 자기소개서 관리를 하나의 플랫폼에서 통합 제공

---

## 기술 스택 (Tech Stack)

- Backend: Python 3.9, Django 4.x, Django REST Framework
- AI / LLM: OpenAI GPT-4o-mini, LangChain
- Database: SQLite
- Frontend: Vue 3, Vite, Pinia
- Styling: CSS
- Collaboration: Git, GitHub

## 추천 알고리즘 기술 설명

1. DART API를 통해 기업 재무제표 데이터 수집
2. 재무상태표, 손익계산서 기반 주요 재무비율 산출
3. 지표별 기준값을 활용한 정규화 처리
4. 카테고리별 가중치 적용
5. 기업 종합 점수 산출
6. LLM을 활용한 추천 사유 및 해석 문장 생성

```text
기업 점수 = Σ(정규화된 지표 값 × 가중치)
```

AI는 수치 계산에는 관여하지 않고, 분석 결과를 자연어로 해석하고 설명하는 역할에 집중

## 핵심 기능 설명

### 회원 관리

* JWT 기반 회원가입, 로그인, 로그아웃
* 마이페이지 제공

### 데이터 관리

* DART 재무제표 데이터 자동 수집 및 저장
* 채용 공고 데이터 수집 및 관리
* 사용자 데이터 관리

### AI 추천

* 사용자 이력 정보 기반 프롬프트 자동 생성
* 점수 기반 기업 추천 결과 제공
* 기업 추천 사유 자연어 설명
* 사용자 이력 기반 채용 공고 매칭 설명 생성


### 사용자 서비스 (기업 / 공채 정보)

* 재무제표 기업 목록 및 검색
* 기업별 재무제표 상세 조회 및 분석
* 채용 공고 목록, 상세 조회 및 북마크

### 개인 맞춤 서비스

* 자기소개서 CRUD 기능

## 회고 (Retrospective)

본 프로젝트는 데이터 수집부터 분석, 추천까지 이어지는 전체 데이터 흐름을 직접 설계하고 구현한 경험이었습니다. 외부 공공 데이터와 내부 서비스 데이터를 결합하면서 데이터 무결성과 구조 설계의 중요성을 체감했으며, AI를 단순 기능이 아닌 해석 도구로 활용하는 방향에 대해 고민할 수 있었습니다. 또한 협업 과정에서 Git과 문서화의 중요성을 깊이 이해하는 계기가 되었습니다.
